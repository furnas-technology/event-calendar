Built-in view controls: set `config.controls` options (`zoom`, `width`, `savePng`, `navigation`, `months`) to `true`
to show A+/A−/Reset, Expand/Fit width, Save PNG, month navigation with the visible range, and a visible-months select
above the drawing. Labels can be replaced with `controls.labels`. The canvas now sits in a `.ft-timeline-viewport`
scroll container inside `.ft-timeline`.
